# assignment_1
BrickView is a web-based real estate intelligence platform designed to simplify property data analysis and management. It provides an interactive interface where users can explore, filter, and visualize real estate datasets with ease.
Key Features -->
Introduction     : A welcoming overview of the platform, setting the stage for users to understand its purpose and scope.
Filter & Explorer: Tools to refine property searches, apply conditions, and navigate large datasets efficiently.
Visualizations   : Graphs, charts, and dashboards that transform raw data into meaningful insights for decision-making.
CURD Operation   : Create, Update, Read, and Delete functionalities to manage property records seamlessly. 
SQL Queries      : A dedicated section for executing and learning SQL queries, enabling advanced users to interact directly with                       the database
